Object-Oriented Programming (OOPS) Architecture

                    
Direct mapping of C++ OOP concepts implemented in main.cpp for CBP Project Viva

                

                
            

            

                

                    

                        
Pillar 1

                        
Encapsulation & Data Hiding

                        
Private/protected state variables (name, id, price, quantity) accessible only through validated getters and setters (e.g., non-negative quantity checks).

                        Component(name, id, price, qty);
void setQuantity(int q); // validates q >= 0
                    


                    

                        
Pillar 2

                        
Hierarchical Inheritance

                        
Specialized hardware categories inherit from Component base class, extending functionality with domain parameters (e.g., Motor adds RPM, Battery adds mAh).

                        class Motor : public Component {
    int operatingVoltage; int rpm;
};
                    


                    

                        
Pillar 3

                        
Runtime Polymorphism

                        
Virtual methods (display(), getType(), toCSV()) dynamically dispatched at runtime via base class pointers (std::shared_ptr<Component>).

                        virtual void display() const;
virtual std::string getType() const;
virtual ~Component() = default;
                    


                    

                        
Pillar 4

                        
Abstraction & Stream I/O

                        
Complex CSV parsing, tokenization, stock reservation validation, and invoice formatting are encapsulated in Inventory and RoboticsProject classes.

                        inventory.loadFromCSV("inventory.csv");
currentProject.exportReceiptTXT("receipt.txt");
